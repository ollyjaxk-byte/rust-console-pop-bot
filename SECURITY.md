# Security Policy

Never commit or paste Discord tokens, RCON passwords, webhook URLs, API keys, private IPs, or connection strings. Rotate exposed credentials immediately.

Public embeds hide server connection details and credentials. Player fields are displayed only when returned by the server. Report vulnerabilities privately with redacted logs. RustPulse Pop does not implement moderation actions, traffic relays, public tunnels, credential harvesting, remote binary execution, or proxy bridges.
