# Command reference

Public: /pop view, /pop status, /rules, /terms.

Staff means server owner, Administrator, Manage Server, or Manage Messages. Staff: /searchplayer username, /pop test, /pop setup, and target-channel posting for /rules and /terms.

RCON data may include server.info, playerlist, status, and users. playerlist is the required roster source. There is no leaderboard or destructive moderation command.
